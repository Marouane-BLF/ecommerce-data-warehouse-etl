# Raw Data

Store the original e-commerce CSV here only after confirming that its source license permits redistribution.

The project report names these source fields: `InvoiceNo`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `UnitPrice`, `CustomerID`, and `Country`.

Record the exact original dataset name, source URL, retrieval date, license, encoding, delimiter, and file hash where practical. Keep the original data unchanged. If the dataset is too large or its license is unclear, keep it out of Git and document instructions for obtaining it.
